# Python Day 155 - Job Application Tracker

## Description
A Python application for managing job applications and tracking their progress through different recruitment stages.

## Features
- Add new job applications
- View all applications
- Search applications by company
- Update application status
- View application summary
- Store data permanently using JSON

## Files
- `job_tracker.py` - Main Python program
- `applications.json` - Application records

## Requirements
- Python 3.x

## How to Run
```bash
python job_tracker.py
```

Keep both files in the same folder.

## Concepts Used
- JSON file handling
- Lists and dictionaries
- CRUD operations
- List comprehensions
- Functions
- Exception handling
